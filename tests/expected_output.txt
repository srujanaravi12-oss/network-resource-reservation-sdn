CHECK all rules removed automatically after expiry: PASS
CHECK server table is empty again: PASS
CHECK reservation still present right after the client died: PASS
CHECK rule removed automatically after the lease ended: PASS
CHECK capacity freed in the server table: PASS
CHECK oversized request rejected: PASS
CHECK rule removed after RELEASE: PASS
CHECK rule removed after expiry: PASS
